# Personal Expense Data Pipeline

## About

This is my first Python project. I built it to practice Python fundamentals by analyzing a list of sample personal expenses.

## What It Does

- Calculates total spending.
- Shows spending by category.
- Finds the category with the highest spending.
- Finds the largest transaction.
- Displays the top 5 largest transactions.

## How It Works

The transaction data is stored in a list of dictionaries in Python. Each transaction has a description, category, and amount.

The program uses functions, loops, dictionaries, and sorting to analyze the data and display the results.
